## Hotel-bookings-data-analysis :
Hotel Booking Data Analysis and Dashboard project using a cleaned and transformed dataset. Includes data preprocessing, booking and cancellation analysis, customer and room insights, revenue estimation, KPIs, and dashboard visualization.

## Project Overview :
This project focuses on analyzing hotel booking data to identify booking patterns, cancellation trends, customer behavior, room information, stay duration, and estimated booking value. The dataset was cleaned and transformed to make it suitable for analysis and dashboard creation.

## Dataset Used :
- <a href="https://github.com/shivanjalisupekar10-dot/hotel-bookings-data- analysis/blob/main/Hotel_Bookings_Cleaned_Transformed.csv%20(1).xlsx">Hotel Booking Dataset

## KPIs Used in the Dataset
Total Bookings – Overall number of hotel reservations.
Cancellation Rate – Percentage of bookings that were cancelled.
Average ADR – Average daily room rate.
Average Lead Time – Average days between booking and arrival.
Total Nights – Total nights spent by guests.
Total Guests – Total number of adults, children, and babies.
